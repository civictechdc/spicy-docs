# Data validation scorecard — 2026-09-21

This is the reconciled inventory for the [validation sprint](data-validation-sprint-2026-09-21.md): **70 tables and 20 source families**, each with four dispositions and a next action. A row combines a structural profile of the selected artifact with the explicitly scoped semantic evidence in its stream report. Current reader behavior can differ from the selected public or local artifact.

**Supported*** means supported only in the named inspected scope, never certified across the source population. **Defect** requires a retained counterexample. **Limited** means coverage or shape restricts the stated use. **Unvalidated** means the required source or output evidence is absent. Empty outputs do not pass semantic checks.

The receipt root is `~/Work/corpora/supply-2026-09-02/receipts/data-validation-sprint-2026-09-21/`. `reconciled-assessments.json` contains all dispositions, exact evidence paths and artifact profiles; `table-scorecard.csv` supports filtering. Artifact profiles carry full paths, SHA-256, column names/types, null counts, candidate key checks and sample paths. The court text cardinality retry uses approximate distinct counts only; identity and null checks remain exact.

Rows from separate tables are not a count of distinct people, documents or events. The comments profile covers 212,733 selected rows out of 23,889,661; its three row groups are deterministic, not a random population sample. Other listed table profiles cover their whole selected files. A local file is not evidence of public availability.
