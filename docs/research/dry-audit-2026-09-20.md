# Duplication audit, 2026-09-20

The largest repeated function family is source-acquirer construction: **220
body-span lines across 15 constructors**, mostly forwarding already-shared
transport settings. The next largest genuine candidates reviewed here are
**60 lines of analysis-mode setup** and **57 lines of date/timestamp checks**.
These are gross regions containing repeated mechanics, **not deletion counts**.
The estimated net savings are much smaller: about 25–35, 35–40 and 20–30 lines,
respectively. The best first extraction is the strict date/timestamp check:
seven callers already want the same validation, and their output formatting
can remain local.

The nine recent table modules mostly declare different facts. Their repeated
column names do not justify a universal shaper. The useful shared mechanics
already live in `schemas/tables.py`; two MODS-to-JSON list builders are a smaller,
real remaining copy. Rule-version builders have different, deliberate inputs;
sharing their serialization would change published digests.

Four offline counterexamples deserve separate correctness work: a retry log
can disclose a query-string credential; an oversized S3 response can leave its
stream open; opaque rule digests do not implement the table abstraction's
"larger means newer" ordering; and `json_column` admits nonstandard JSON numbers.
No behavior, symbol, module location, contract, fixture, or existing test changed
in this audit. Nothing was pushed and no network request was made.

- **Exact functions:** equal AST bodies, excluding docstrings, signatures,
  decorators and positions, and other standalone string statements. This ignores formatting but preserves names and
  values. Equal bodies referring to different module globals are still only
  candidates.
- **Near functions:** equal shapes after replacing variable names in first-use
  order and replacing literal values with their types. Repeated bindings remain
  significant; attribute and keyword names remain significant. This catches
  renamed/literal-edited copies, not every edit-distance clone.
- **Blocks:** windows of 3–6 adjacent statements in every suite, including module
  and class declarations. Minimum span is four physical lines. Contained groups
  with the same occurrence coverage are suppressed; crossing windows still
  overlap. Imports and data declarations remain visible as false positives.
- **Literals:** strings of at least four characters and numeric literals with
  absolute value at least two, excluding docstrings. **Regexes:** direct literal
  patterns in `re.compile/search/match/fullmatch/finditer/findall/sub/subn/split`.
  The pattern inventory ignores flags; aliases, flag differences and computed patterns need manual inspection.
- **Errors:** direct string or f-string first arguments in `raise` calls, with
  interpolation replaced by `{}`. Different templates and indirect builders are
  not grouped together.
